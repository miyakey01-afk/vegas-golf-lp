# vegas-golf-lp

「ラスベガス・ゴルフ・ゲーム」（iOS App Store）の紹介用ランディングページです。
静的な1ページ（`index.html`）を GitHub Pages でそのまま公開しています。

- 公開URL: https://miyakey01-afk.github.io/vegas-golf-lp/
- アプリ本体: https://apps.apple.com/jp/app/id6768002657

## 構成
- `index.html` — LP本体（このファイル1つで完結）
- `assets/` — 画像（アイコン・スクリーンショット・OGP画像など）
- `.nojekyll` — GitHub PagesのJekyll処理を無効化するための空ファイル
